# DilYol — 55 Dil · Etaplı Öğrenme

Şekilli, mobil uyumlu dil öğrenme sitesi. Sunucu gerekmez.

## Özellikler
- **55 dil** (Avrupa, Asya, Ortadoğu, diğer)
- Her dilde **5 etaplı yol** (kilitli ilerleme)
- Kelime listesi, kartlar, cümleler, quiz
- **Genel sınav** (15 soru, karışık)
- XP, gün serisi, günlük hedef
- Arama + bölge filtreleri
- İlerleme telefonda saklanır (localStorage)

## Zengin içerik
İngilizce, Almanca, İspanyolca, Fransızca, Japonca, Korece, Çince, Rusça, Arapça, Türkçe tam etaplı.
Diğer dillerde gerçek selamlama paketleri + evrensel etap yapısı.

## Açma
`index.html` dosyasını tarayıcıda aç.

GitHub Pages: repo → Settings → Pages → main / root
